## Project Description

This project is about building a mini-internet using Python 3 and UDP sockets. The network will contain hosts and routers that communicate using virtual addresses and forwarding tables.

Our first goal is to build the common network and demonstrate communication between hosts through multiple routers.

## Tentative Extension

**Track B – Reliable Transfer**

We plan to implement reliable transfer using acknowledgments, sequence numbers, timeouts, retransmissions, and duplicate detection.
